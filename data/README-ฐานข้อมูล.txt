ฐานข้อมูลกลางของระบบ (SQLite)
==============================
ไฟล์: data/db.sqlite
  samples = ผลตรวจที่บันทึกไว้ (ลำดับที่ / label / ฟาร์ม / ผล / ความเชื่อมั่น / ผู้ตรวจ)
  farmers = ทะเบียนฟาร์ม ใช้เติมช่อง 'ฟาร์มที่มาของตัวอย่าง'
  meta    = เวอร์ชันสูตรฐานข้อมูล

สำรองข้อมูล: ดับเบิลคลิก สำรองฐานข้อมูล.bat  (ได้ไฟล์ data/backup-<เวลา>.json)
กู้คืนข้อมูล: วางไฟล์ backup-*.json ไว้ในโฟลเดอร์ data แล้วรัน คืนค่าฐานข้อมูล.bat

ถ้าใช้บนคลาวด์ (Render free) พื้นที่เก็บไฟล์จะหายเมื่อรีสตาร์ต
ให้ใช้ปุ่ม 'ส่งออกทั้งหมด (JSON)' บนหน้าเว็บเก็บไว้ หรือต่อฐานข้อมูลภายนอก

แบบจำลอง liverV1.pt (6.3 MB) คัดลอกเข้า git แล้ว จึงขึ้นเว็บไปพร้อมโฟลเดอร์
ถ้าเว็บติดตั้ง torch + ultralytics ตาม requirements.txt จะประเมินภาพได้เอง
ถ้าไม่ติดตั้ง ให้ตั้ง LIVER_ENGINE ชี้ไปที่เครื่องที่รัน start.bat แทน
