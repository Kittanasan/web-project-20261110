หน้าหลัก › งานตรวจคุณภาพสัตว์น้ำ › ประเมินเม็ดไขมันในตับ

ระบบประเมินเม็ดไขมันในตับจากภาพถ่าย (Image-Based Fat Assessment) กำลังตรวจสอบสถานะ…

แนบภาพถ่ายตัวอย่างตับเพื่อให้แบบจำลองช่วยคัดกรองระดับเม็ดไขมัน แล้วให้เจ้าหน้าที่ตรวจทานและยืนยันผลก่อนบันทึก

กำลังตรวจสอบสถานะเครื่องประมวลผล…
คู่มือติดตั้งระบบบนเครื่องอื่น (เปิดเมื่อย้ายเครื่อง)
  1. คัดลอก โฟลเดอร์โปรแกรมทั้งหมด ไปยังเครื่องปลายทาง (ต้องมี app.py, Index.html, live.js, liverV1.pt และโฟลเดอร์ assets)
  2. เครื่องปลายทางต้องมี Python ที่ติดตั้ง torch + ultralytics — วิธีที่ง่ายที่สุดคือคัดลอกโฟลเดอร์ runtime\python311 จากเครื่องที่ใช้งานได้ มาวางไว้ข้าง start.bat (path ต้องเป็น runtime\python311\python.exe) ระบบจะใช้เองอัตโนมัติ
  3. หรือติดตั้ง Python 3.11 (64-bit) บนเครื่องปลายทางแล้วรันคำสั่ง pip install ultralytics (ต้องมีพื้นที่ว่างราว 5 GB)
  4. ดับเบิลคลิก ตรวจสอบระบบ.bat — จะบอกทีละข้อว่าขาดอะไร และทดลองวิเคราะห์ภาพจริงให้ดู
  5. ถ้าผ่านทุกข้อ ดับเบิลคลิก start.bat แล้วเปิด http://127.0.0.1:8000 (หรือให้เครื่องอื่นในวงเดียวกันใช้ได้ ให้ตั้ง LIVER_HOST=0.0.0.0 ก่อนเปิด แล้วเปิดด้วย IP ของเครื่องนี้)
  6. ถ้าขึ้นว่าเชื่อมต่อเครื่องประมวลผลไม่ได้: ดูข้อความในหน้าต่าง start.bat ว่าแจ้ง error อะไร (โดยทั่วไปคือ “ไม่พบ Python ที่มี torch/ultralytics” หรือพอร์ต 8000 ถูกโปรแกรมอื่นใช้)
  7. ถ้าขึ้นว่า “เซิร์ฟเวอร์ตอบ แต่ไม่มีตัววิเคราะห์” = ตัวที่รัน app.py อยู่เป็น Python ธรรมดา ที่ไม่มี torch/ultralytics ให้ปิดหน้าต่างนั้นแล้วเปิดด้วย start.bat เท่านั้น (start.bat จะเลือก Python ที่มี torch ให้เอง)
รายละเอียดทุกกรณีอยู่ในไฟล์ README-ติดตั้งเครื่องใหม่.txt ข้าง app.py
