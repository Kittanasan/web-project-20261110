========================================================================
 ติดตั้งระบบประเมินเม็ดไขมันในตับจากภาพ ไปใช้บนเครื่องอื่น
 (แบบจำลอง liverV1.pt / ศูนย์วิจัยและพัฒนาการเพาะเลี้ยงสัตว์น้ำชายฝั่งฉะเชิงเทรา)
========================================================================

อาการที่พบบ่อย: คัดลอกโปรแกรมไปเครื่องใหม่แล้ว เปิดหน้าเว็บได้
แต่กดประเมินภาพแล้วไม่ขึ้นผล หรือขึ้นว่า "เชื่อมต่อเครื่องประมวลผลไม่ได้"

สาเหตุเกือบทั้งหมด: เครื่องใหม่ยังไม่มีตัววิเคราะห์ (Python + torch +
ultralytics) หรือคัดลอกไฟล์ไม่ครบ เพราะระบบนี้ประมวลผลในเครื่องเอง
ไม่ใช้เซิร์ฟเวอร์บนอินเทอร์เน็ต


------------------------------------------------------------------------
 ขั้นตอนที่ 1: คัดลอกอะไรไปบ้าง
------------------------------------------------------------------------
คัดลอก "ทั้งโฟลเดอร์โปรแกรม" (ไม่ใช่เลือกเฉพาะไฟล์ .bat) ต้องมี:

  app.py                 ตัวเซิร์ฟเวอร์และตัวเรียกแบบจำลอง
  Index.html             หน้าเว็บใช้งาน
  live.js                ตัวเชื่อมต่อเครื่องประมวลผล
  liverV1.pt             แบบจำลอง (ขนาดใหญ่สุด ประมาณ 6 MB)
  start.bat              เปิดระบบ (ดับเบิลคลิก)
  ตรวจสอบระบบ.bat        ตรวจว่าเครื่องใหม่พร้อมหรือไม่
  diagnose.py            ตัวตรวจละเอียด (เรียกจาก ตรวจสอบระบบ.bat)
  check_system.py        ตัวตรวจแบบเดิม (เรียกจาก ตรวจสอบระบบ.bat)
  assets\                โฟลเดอร์ตรากรมประมง
  runtime\python311\     โฟลเดอร์ Python พร้อมไลบรารี (ถ้ามี) ~ 5 GB

ข้อควรระวัง
  - ถ้าคัดลอกผ่าน USB ให้คัดลอกทั้งโฟลเดอร์ (ไฟล์ใหญ่ใช้เวลานาน)
  - ถ้าคัดลอกผ่าน OneDrive/อีเมล ไฟล์ liverV1.pt อาจถูกบล็อกหรือถูกตัดขนาด
    ให้เทียบขนาดไฟล์กับเครื่องต้นทาง
  - อย่าวางไว้ใน C:\Program Files หรือโฟลเดอร์ที่ต้องสิทธิ์ผู้ดูแลระบบ
    เพราะจะเขียนไฟล์ผลการตรวจ (exports\) ไม่ได้


------------------------------------------------------------------------
 ขั้นตอนที่ 2: ตรวจว่าเครื่องใหม่พร้อม
------------------------------------------------------------------------
ดับเบิลคลิก  ตรวจสอบระบบ.bat
ระบบจะแสดงทีละบรรทัด PASS / WARN / FAIL และบอกว่าติดข้อไหน

  ถ้าขึ้น FAIL "ไม่มี torch" หรือ "ไม่มี ultralytics"  => ไปขั้นตอนที่ 3
  ถ้าขึ้น FAIL "ไม่พบ liverV1.pt"                      => คัดลอกไฟล์มาให้ครบ
  ถ้าขึ้น FAIL "เขียน exports/ ไม่ได้"                  => ย้ายโฟลเดอร์โปรแกรม
                                                         ไปไว้ใน Documents
  ถ้าทุกข้อ PASS                                        => ใช้งานได้เลย


------------------------------------------------------------------------
 ขั้นตอนที่ 3: ทำให้เครื่องใหม่มีตัววิเคราะห์
------------------------------------------------------------------------
วิธีที่เร็วและไม่ต้องต่ออินเทอร์เน็ต (แนะนำ)
  1) ที่เครื่องต้นทาง เปิดโฟลเดอร์โปรแกรม จะเห็นโฟลเดอร์ runtime
     (ข้างในคือ runtime\python311\python.exe พร้อมไลบรารีทั้งหมด ~ 5 GB)
  2) คัดลอกโฟลเดอร์ runtime ทั้งโฟลเดอร์ ไปวางไว้ในโฟลเดอร์โปรแกรม
     ของเครื่องใหม่ ให้ได้ตำแหน่ง:
        <โฟลเดอร์โปรแกรม>\runtime\python311\python.exe
  3) ดับเบิลคลิก ตรวจสอบระบบ.bat อีกครั้ง แล้วดับเบิลคลิก start.bat

วิธีที่ต้องต่ออินเทอร์เน็ต (ถ้าคัดลอก runtime ไม่ได้)
  1) ติดตั้ง Python 3.11 (64-bit) จาก https://www.python.org/downloads/
     ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH"
  2) เปิด Command Prompt แล้วพิมพ์:
        pip install ultralytics
     (ดาวน์โหลดประมาณ 3-5 GB ใช้เวลานาน ต้องมีที่ว่างในไดรฟ์ C: อย่างน้อย 8 GB)
  3) ดับเบิลคลิก start.bat


------------------------------------------------------------------------
 ขั้นตอนที่ 4: การใช้งานและสิ่งที่ต้องระวัง
------------------------------------------------------------------------
  - ดับเบิลคลิก start.bat แล้วรอ 20-40 วินาที (ครั้งแรกจะช้ากว่า)
    หน้าต่างดำต้องเปิดค้างไว้ตลอดการใช้งาน
    start.bat จะบอกทีละขั้น [1/5] ถึง [5/5] ว่ากำลังทำอะไรและติดอะไร
  - start.bat หา Python ที่มี torch + ultralytics ให้เองทีละตัว
    (runtime ในโฟลเดอร์ -> OneDrive/Desktop เดิม -> พอร์ต/ไดรฟ์อื่นในเครื่อง -> python ในเครื่อง)
    ถ้าไม่พบเลย จะพยายามคัดลอกโฟลเดอร์ runtime จากเครื่องเดิมให้เองก่อนจะฟ้อง error
  - ถ้าพอร์ต 8000 ถูกโปรแกรมอื่นใช้ start.bat จะเลือกพอร์ตถัดไปให้เอง (8001, 8002 ...)
    และจะบอก URL ที่ต้องเปิดในหน้าต่างดำ (หน้าเว็บก็หาเจอเองเช่นกัน)
    ถ้าต้องการกำหนดเอง ให้ตั้ง LIVER_PORT ก่อนเปิด เช่น   set LIVER_PORT=8100
  - ค่าเริ่มต้นเปิดที่ http://127.0.0.1:8000 ใช้ได้ภายในเครื่องนั้นเท่านั้น
  - ถ้าต้องให้เครื่องอื่นในวงเดียวกันเปิดผ่าน LAN
        set LIVER_HOST=0.0.0.0
    แล้วเปิดจากเครื่องอื่นที่ http://<IP ของเครื่องนี้>:8000
    (ต้องอนุญาตผ่าน Windows Firewall - ระบบจะถามครั้งแรก ให้กด Allow)
  - ผลการตรวจและภาพผลประเมินถูกบันทึกไว้ในโฟลเดอร์ exports\
    ของเครื่องที่รันโปรแกรม (ไม่ขึ้นกับเครื่องที่เปิดหน้าเว็บ)
  - ภาพและผลการประเมินไม่ออกจากเครื่อง ไม่มีการส่งขึ้นอินเทอร์เน็ต


------------------------------------------------------------------------
 ถ้ายังแก้ไม่ได้
------------------------------------------------------------------------
เปิดหน้าต่างดำที่รันอยู่ แล้วคัดลอกข้อความบรรทัดที่ขึ้นต้นด้วย
  [FAIL] ...   หรือ   [error] ...
ส่งมาให้ผู้ดูแลระบบ พร้อมภาพหน้าจอของ ตรวจสอบระบบ.bat
ข้อความนั้นระบุสาเหตุไว้ตรง ๆ ว่าเป็นเรื่อง Python, แบบจำลอง, สิทธิ์ไฟล์
หรือพอร์ต จึงแก้ได้ตรงจุด
